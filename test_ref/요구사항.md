# VSM(Vehicle Speed Monitor) 요구사항 명세 — v1

가상 시나리오입니다. 실습 예제 코드의 기준이 되는 명세입니다.

## 1. 개요

VSM 은 차속 센서 값을 주기적으로 읽어 잡음을 제거하고, 차속에 따라 경고 등급을 판정하여
진단 이력에 기록하는 ECU 소프트웨어 컴포넌트다.

## 2. 기능 요구사항

| ID | 요구사항 | 관련 구현 |
|---|---|---|
| SR-001 | VSM 은 차속을 km/h 단위의 부호 없는 정수로 취급해야 한다. | `vsm_types.h` |
| SR-002 | 차속이 과속 기준에 이르면 경고 등급을 `HIGH` 로 판정해야 한다. | `sm_evaluate()` |
| SR-003 | 차속이 주의 기준을 넘으면 경고 등급을 `MID` 로 판정해야 한다. | `sm_evaluate()` |
| SR-004 | 센서 값은 최근 값들을 링 버퍼에 유지해야 한다. | `sf_push()` |
| SR-005 | 과속 카운터는 `sm_reset()` 호출로 초기화된다. | `sm_reset()` |
| SR-006 | 판정된 경고 등급은 매 주기 진단 이력에 기록되어야 한다. | `dl_record()` |
| SR-007 | 센서 평균은 넣은 샘플들의 평균이다. | `sf_average()` |
| SR-010 | 과속 카운터는 경고 등급을 `HIGH` 로 판정할 때마다 늘어야 한다. | `sm_evaluate()` · `sm_over_count()` |
| SR-011 | 임계값 문자열을 숫자로 해석해야 한다. | `dl_parse_threshold()` |
